# MiniatureCarCollector

**MiniatureCarCollector** is a custom-built desktop application designed for die-cast enthusiasts, hobbyists, and serious collectors to effortlessly organize, track, and manage their miniature car collections.

Whether you're organizing classic mainstream models, hunting down rare collector editions, or keeping tabs on market values, this tool provides a sleek and centralized garage management experience right on your Windows desktop.

---

## ✨ Key Features

* **Garage Inventory Management:** Easily catalog your die-cast vehicles, tracking key details, acquisition notes, and custom categories.
* **Sleek & Responsive Interface:** Built with a clean UI optimized for desktop use, featuring custom audio cues for smooth interactions.
* **Local Database Storage:** Keeps your entire collection secure and accessible locally via an embedded database backend.
* **Modern Packaging:** Deployed via a seamless MSIX installer package for smooth Windows integration and native execution.

---

## 🛠️ How to Install

Because this build is signed with a custom developer certificate, follow these quick steps to install it on Windows:

### Step 1: Install & Trust the Certificate
1. Download **`DevCert.pfx`** and double-click it to open the Certificate Import Wizard.
2. Select **Local Machine** as the Store Location and click **Next**.
3. Enter the certificate password (`Thejan2013`) and click **Next**.
4. Select **Place all certificates in the following store**.
5. Click **Browse...**, select **Trusted Root Certification Authorities**, and click **OK**.
6. Click **Next** and then **Finish**.

### Step 2: Install the Application
1. Double-click **`MiniatureCarCollector.msix`**.
2. Click **Install**.
3. Launch the app directly from your Start Menu and start organizing your collection!
